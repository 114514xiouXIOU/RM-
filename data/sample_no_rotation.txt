# 重投影算例输入文件
#
# 格式说明（程序会跳过所有以 # 开头的整行）：
#   第 1 行： num_points（点的个数）
#   第 2 行： fx fy cx cy width height     （内参；width/height 填 0 表示不检查是否在画面内）
#   第 3~5 行：旋转矩阵 R，行优先 9 个数   （世界 -> 相机）
#   第 6 行： 平移 t = tx ty tz            （与三维点同样的长度单位）
#   之后每行： Xw Yw Zw  u_obs v_obs       （世界点 + 观测到的像素）
#
# 本算例：无旋转（R = 单位矩阵），t = (0, 0, -1000)
#   Pc = Pw + t，所以"相机坐标系"就是把世界坐标在 Z 方向减去 1000。
#   换个角度看：相机光心位于世界坐标 (0, 0, 1000)，光轴指向世界 +Z 方向。
#
# 理论正确答案（可用来对答案）：
#   点1：Pw=(0, 0, 1000) -> Pc=(0, 0, 0) -> 无效！
#        ⚠️ 这个点正好落在相机光心上，投影没有意义。程序必须把它标成"无效"，
#           而不是输出 (640, 360)。这是新手最容易漏掉的边界情况。
#   点2：Pw=(0, 0, 2000) -> Pc=(0, 0, 1000) -> u = 800*0/1000 + 640 = 640.000
#                                            v = 800*0/1000 + 360 = 360.000
#        观测 (640.0, 360.0) -> 误差 0.0000 px
#   点3：Pw=(100, 50, 3000) -> Pc=(100, 50, 2000)
#        u = 800*100/2000 + 640 = 680.000
#        v = 800*50/2000 + 360 = 380.000
#        观测 (680.5, 385.5) -> 误差 sqrt(0.5^2 + 5.5^2) = 5.5227 px
#   点4：Pw=(0, 0, 500) -> Pc=(0, 0, -500) -> 无效（点在相机后方，Zc < 0）

4

# 内参：fx fy cx cy width height
800 800 640 360 1280 720

# 外参 R：单位矩阵，表示相机没有旋转
1 0 0
0 1 0
0 0 1

# 外参 t：世界 -> 相机的平移
0 0 -1000

# 世界点 + 观测像素
0     0     1000    640.0 360.0
0     0     2000    640.0 360.0
100   50    3000    680.5 385.5
0     0      500    640.0 360.0
